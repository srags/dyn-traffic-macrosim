# Agent Instructions

These rules apply to all future work in this repository.

## Git

- Do not run `git add`, `git commit`, or `git push`.
- Do not stage or commit changes on behalf of the user, even if asked to "save" or "commit" work — leave git operations to the user.

## Data folder

- Do not create, modify, or delete anything inside the `data/` directory.
- Treat `data/` as read-only. If a task seems to require writing to it, stop and ask the user first.
